# DCGAN - Face Generation using Deep Convolutional GAN

## 📌 Project Overview

This project implements a **Deep Convolutional Generative Adversarial Network (DCGAN)** using PyTorch to generate realistic human face images from random noise vectors.

The model is trained on the CelebA dataset and learns the underlying distribution of facial features, enabling it to generate entirely new synthetic faces.

---

## 🚀 Features

- Deep Convolutional GAN (DCGAN) Architecture
- Trained on the CelebA Face Dataset
- Generator and Discriminator Networks implemented using PyTorch
- Custom Weight Initialization
- Image Generation from Random Noise
- Model Saving and Loading
- Visualization of Generated Faces

## 🏗️ DCGAN Architecture
Generator

The Generator takes a random noise vector and converts it into a realistic face image using:

- ConvTranspose2D Layers
- Batch Normalization
- ReLU Activation
- Tanh Output Layer
- Discriminator

The Discriminator classifies whether an image is:

Real (from dataset)
Fake (generated by Generator)

It consists of:

- Conv2D Layers
- Batch Normalization
- LeakyReLU Activation
- Sigmoid Output Layer
